# Forms

A form is a validated `TextField` with an inline error, and a Submit button that only enables once
the field is valid.

For the headless test pattern that exercises a form without a window, see
[`docs/testing.md`](https://github.com/vanyastaff/flui/blob/main/docs/testing.md), and
[Testing](testing.md) for the equivalent on the counter example.
