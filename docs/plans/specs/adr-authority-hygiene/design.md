# ADR authority and retirement design

**Status:** Approved by the maintainer on 2026-10-11; documentation implementation in progress.

**Requirements:** [#1553](https://github.com/vanyastaff/flui/issues/1553).

Factual corrections are explicit dated amendments. Acceptance, implementation and executed evidence remain separate. Semantic reversals require their own precise supersession and do not follow from cleanup alone.

Keep ADR-0125, ADR-0179 and ADR-0191 as independently reversible identity, controller-lifetime and topology decisions. One existing architecture map connects them; source contracts and tests keep their present authority. Only proven duplicated explanation is shortened.

For ADR-0016, ADR-0059 and ADR-0077, map every surviving font/shaping/family-resolution clause to Accepted ADR-0092 and preserve historical experiment rationale through immutable links. Migrate every tracked incoming reference before removing records with no independent authority. Do not reuse retired numbers. ADR-0102 stays; ADR-0057/0099 remain conditional; Proposed records and incomplete ADR-0142 obligations are not silently accepted or retired.

Existing repository documentation gates prove resolvable references and valid format; the source/test-authority review proves the migration did not lose a current rule. Docs-only checks make no new native, performance or conformance claim. Behavioral defects return to separately approved source work.
