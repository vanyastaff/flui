# flui-animation / catalog-components — требования

- **Статус:** на утверждении (решения K1–K5 — владелец; K6–K12 делегированы и закрыты
  исследованием, см. design «Решения»)
- **Дата:** 2026-10-17
- **База:** `main` 4967778a1.
- **Связанные:** [design.md](design.md), [tasks.md](tasks.md); предыдущий раунд
  [catalog](../catalog/requirements.md) (его «Вне объёма» — исходный список этого раунда);
  ADR-0088 (поверхность SDK), ADR-0192 (индикаторы под reduce motion), ADR-0195/ADR-0218
  (политика движения), ADR-0013 (движение из layout).

## Пользовательский сценарий

Автор приложения получает готовые компоненты, которые в других экосистемах приходят из
сторонних пакетов: анимированные иконки и эффекты на любой иконке, список и сетку с
перетаскиванием, карусель Material 3, индикаторы прогресса и загрузки Material 3 Expressive,
индикатор страниц и эффекты частиц (конфетти, искры, снег). Каждый компонент уважает reduce
motion, доступен с клавиатуры и для ассистивных технологий там, где он интерактивен, и
проверяется тестом через публичный API.

## Текущее состояние (чтением)

- `Icon` рисует глиф шрифта (`IconData` = код + семейство); векторных иконок и анимированных
  иконок нет; `Icon` не читает `Directionality`.
- `Path` (обёртка `kurbo::BezPath`) умеет строить контуры и `translate`, но не даёт длины,
  под-пути, аффинного преобразования и морфа; примитива скруглённых многоугольников нет.
- Есть `Draggable<T>`, `DragTarget<T>`, `Dismissible`, `MultiDragGestureRecognizer`; нет
  long-press варианта (нет отложенного multi-drag распознавателя) и автопрокрутки у краёв.
  Разница ключей и FLIP-сдвиг есть у `AnimatedList` (`scroll/animated_list/roster.rs`).
- `PageView`/`PageController`/`PageScrollPhysics`; дети создаются сразу (`SliverFillViewport`
  без ленивого делегата); других физик привязки нет; карусели и индикатора страниц нет.
- `ActivityIndicator` (общий), `LinearProgressIndicator` (Material), `CupertinoActivityIndicator`;
  нет `CircularProgressIndicator`, волнистых вариантов, `LoadingIndicator`.
- `Canvas::draw_atlas` записывает инстансные спрайты и движок их рисует, но ни один виджет его
  не использует; частиц нет.
- Поверхность SDK для рисования узкая: нет `Image`, `BlendMode`, шейдеров, `Matrix4`.

## Требования

ID — только в этом каталоге. «Таблица» — строка существующего runner'а крейта; виджетные
тесты — `flui_testing::widgets::lay_out_animated` + `pump_for` на виртуальных часах, кадр
читается из записанного display list. Каждое требование закрывается тестом, падающим без
реализации.

### Геометрия путей и форм (G)

- **G1** `Path::length()`, `Path::trim(start, end)` (доли длины, перенос через 0 для
  смещения), `Path::transform(&Matrix4)` на основе kurbo; конечные результаты для вырожденных
  путей.
- **G2** `Path::lerp(a, b, t)` для совместимых путей (одинаковые последовательности команд);
  несовместимые возвращают `None`, а не мусор.
- **G3** `RoundedPolygon` (вершины со скруглением и сглаживанием, звёзды, «печенья») и
  `Morph::new(a, b)` с `Morph::path(t)`; набор форм M3 Expressive (`MaterialShapes`), из
  которого строятся индикаторы.

### Анимированные иконки и эффекты (I)

- **I1** `AnimatedIconData`: ключевые кадры векторных путей (команды move/line/cubic/close,
  непрозрачность слоя) с кривыми между кадрами; `AnimatedIcon::new(data, progress)` рисует
  кадр по `Animation<f64>`, цвет и размер из `IconTheme`, зеркалирование под RTL по флагу
  данных.
- **I2** Набор Material-пар (play_pause, pause_play, menu_arrow, arrow_menu, menu_close,
  close_menu, search_ellipsis, ellipsis_search, add_event, event_add, home_menu, menu_home,
  list_view, view_list) из исходников Material (Apache-2.0).
- **I3** `cargo xtask icon-import`: конвертер из Android AnimatedVectorDrawable XML и из пары
  SVG-путей с совместимыми командами в `AnimatedIconData`; отказ с понятной ошибкой на
  несовместимых путях.
- **I4** `SymbolEffect` на любой иконке (глиф или вектор): дискретные (`bounce`, `wiggle`,
  `rotate`) по смене значения, бесконечные (`pulse`, `breathe`, `rotate`) пока активны,
  переходы (`appear`, `disappear`, `draw_on`/`draw_off` через обрезку пути для векторных),
  `replace` между двумя иконками; опции `repeat(n)`, `speed(x)`.
- **I5** Семантика: метка живёт на иконке, анимация не объявляется; `replace` объявляет
  только новую метку.

### Перетаскивание в списках и сетках (R)

- **R1** `ReorderableList`, `ReorderableGrid`, `SliverReorderableList` с ключами элементов;
  `on_reorder(from, to)` вызывается один раз при отпускании, `to` уже учитывает удалённый
  элемент; `on_reorder_preview` — необязательный колбэк хода жеста; `on_reorder_start/end`.
- **R2** Запуск: ручка (`ReorderHandle`, немедленно) и long-press на элементе; по умолчанию
  ручка на десктопе, long-press на мобильных; `LongPressDraggable<T>` и отложенный
  multi-drag распознаватель — общие, доступны и вне списка.
- **R3** Поднятый элемент через `proxy_decorator(child, index, animation)` (по умолчанию
  высота 0→6 и масштаб 1→1.02 за 150 мс); соседи сдвигаются за 250 мс; бросок садится в слот
  за 250 мс.
- **R4** Автопрокрутка у краёв со скоростью по глубине захода в зону; перетаскиваемый элемент
  остаётся живым, когда уходит из построенного диапазона ленивого списка.
- **R5** Клавиатура: на ручке или элементе Space/Enter поднимает, стрелки двигают на слот,
  Space/Enter бросает, Esc отменяет и возвращает исходный индекс.
- **R6** Действия ассистивных технологий: «в начало», «вверх/влево», «вниз/вправо», «в
  конец», с учётом оси и RTL, скрыты на границах; объявление «перемещено, позиция n из N».
- **R7** Отмена (Esc, потеря захвата указателя, размонтирование) возвращает элемент без
  вызова `on_reorder`.

### Карусель (C)

- **C1** Общий `Carousel` в `flui-widgets` на модели ключевых линий: раскладки
  `MultiBrowse { min_small, max_small }`, `Uncontained { item_extent }`,
  `Hero { alignment }`, `FullScreen`, `Weighted(weights)`; элементы раскладываются в большом
  размере и маскируются, а не сжимаются; ленивые дети.
- **C2** `CarouselItemScope` отдаёт текущий прямоугольник маски и долю между ключевыми
  линиями (параллакс внутри элемента).
- **C3** Поведение броска: `SingleAdvance` (пружина medium-low, ровно один элемент за бросок
  при любой скорости), `MultiBrowse` (затухание и привязка к ключевой линии), `Free`.
- **C4** `CarouselController`: `index()`, `animate_to_item`, `jump_to_item`; `on_index_changed`.
- **C5** Автопрокрутка (opt-in) с гарантиями WCAG 2.2.2 и шаблона карусели W3C: период не
  меньше 5 с; обязательный контроль паузы; остановка на фокусе клавиатуры, фокусе
  ассистивных технологий, наведении, нажатии и потере фокуса окна, без самовозобновления;
  без объявлений во время вращения; выключена под reduce motion.
- **C6** Семантика: горизонтальный прокручиваемый контейнер с «n из N» на элемент и
  действиями прокрутки вперёд/назад.
- **C7** Material `CarouselView`: элементы-карточки M3 (форма, высота, рябь `InkWell`, тап),
  токены и значения по умолчанию M3 (малый элемент 40–56 dp).

### Индикаторы (P)

- **P1** Material `CircularProgressIndicator` (определённый и неопределённый, M3: 40 dp,
  толщина 4 dp, цикл 6000 мс) и зазор трека и stop-точка у линейного и кругового (4 dp).
- **P2** Волнистые варианты: линейный (длина волны 40 dp определённый / 20 dp
  неопределённый, амплитуда 3 dp, волна идёт на длину волны в секунду, амплитуда 0 при
  прогрессе ≤10 % и ≥95 % с переходом 500 мс) и круговой (48 dp, амплитуда 1.6 dp, длина
  волны 15 dp, подогнанная к окружности).
- **P3** `LoadingIndicator` и `ContainedLoadingIndicator`: контейнер 48 dp, форма 38 dp,
  семь форм по кругу (SoftBurst, Cookie9Sided, Pentagon, Pill, Sunny, Cookie4Sided, Oval),
  морф каждые 650 мс на пружине (затухание 0.6, жёсткость 200) с +90° за морф и полным
  оборотом за 4666 мс; определённый вариант морфит круг в SoftBurst по прогрессу.
- **P4** `PageIndicator` в `flui-widgets`: следует дробной позиции страницы (`PageController`
  или любой `Animation<f64>`); тап по стороне листает на одну страницу; скрыт при одной
  странице; оконный режим при многих страницах (крайние точки уменьшаются); семантика
  «регулируемый», значение «страница n из N», действия увеличения/уменьшения.
  `CupertinoPageControl` в `flui-cupertino` поверх него.
- **P5** Семантика индикаторов: определённый — диапазон прогресса, неопределённый — «занято»;
  анимация никогда не единственный сигнал.

### Частицы (X)

- **X1** `ParticleEmitter` (виджет) с декларативной конфигурацией: форма источника (точка,
  линия, прямоугольник, круг, кольцо; площадь или контур), частота или всплески, ёмкость,
  длительность или цикл; на частицу — время жизни, скорость и направление с разбросом,
  начальные размер, поворот, вращение; гравитация и сопротивление; цвет, размер и
  непрозрачность по времени жизни.
- **X2** `ParticleController::emit_burst(count)` и `emit_burst_at(point, count)` для событий.
- **X3** Пресеты: `confetti`, `sparkle`, `snow`.
- **X4** Отрисовка одним `draw_atlas` за кадр; спрайты (квадрат, круг, звезда) рисуются в
  атлас один раз; пользовательский спрайт из `Image`.
- **X5** Детерминизм: сид ГПСЧ даёт одинаковую последовательность кадров (тесты сравнивают
  записанные кадры).
- **X6** Тик останавливается, когда излучатель пуст и закончен, невидим (`TickerMode`) или
  размонтирован; ёмкость ограничена; частицы исключены из семантики; пресеты не мерцают
  чаще 3 раз в секунду (WCAG 2.3.1).

### Reduce motion (M)

- **M1** Одна таблица поведения под `MotionOverride::Reduce` (design «Reduce motion»),
  строка на компонент, каждая строка — тест.

### Сквозные (Z)

- **Z1** Новые публичные элементы, нужные пакетам, — в `flui-sdk` по ADR-0088 §4 со строкой
  в `tests/surface.rs` (в том числе расширение поверхности рисования: `Image`,
  `BlendMode`, `Matrix4`, формы).
- **Z2** У каждого нового публичного элемента есть production-потребитель в этом наборе
  работ.
- **Z3** Каждый новый render object — строка `RENDER_OBJECT_TYPES` и `harness_*`.
- **Z4** Фрагменты `changelog.d/`, обновлённые `ARCHITECTURE.md` затронутых крейтов, сцены в
  `examples/motion_lab.rs`.

## Вне объёма

- **Lottie** — решение владельца (K2): не в этом раунде. Изучение кода показало, что плеер
  ложится на существующую отрисовку, если закрыть обрезку путей (её даёт G1), градиент на
  произвольном пути, люма-маски на `SaveLayer`, miter limit и смещение контура.
- **Rive** — решение владельца (K1): нет зрелого Rust-рантайма.
- Анимация осей вариативного шрифта Material Symbols (шрифт не поставляется).
- GPU-частицы (вычислительные шейдеры): UI-масштаб покрывается CPU-симуляцией.
- Градиент на произвольном пути, который движок сейчас рисует сплошным цветом, — дефект
  движка, отдельная задача вне этого спека.
