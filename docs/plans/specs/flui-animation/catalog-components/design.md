# flui-animation / catalog-components — design

- **Статус:** утверждён (см. [requirements.md](requirements.md))
- **Дата:** 2026-10-17
- **База:** `main` 4967778a1.

## Решения

| # | Решение | Почему | Кем |
|---|---|---|---|
| K1 | Rive не делаем | Нет зрелого Rust-рантайма: `rive-rs` не опубликован и требует сборки C++ | владелец |
| K2 | Lottie не в этом раунде | Решение владельца после разбора пробелов отрисовки (requirements «Вне объёма») | владелец |
| K3 | `AnimatedIcon` — ключевые кадры векторных путей плюс словарь эффектов в духе SF Symbols для любой иконки | Набор Flutter заморожен на 7 парах без конвейера авторинга; оси вариативного шрифта требуют поставки шрифта и перерастеризации глифов | владелец |
| K4 | Индикаторы M3 Expressive с собственными `RoundedPolygon`/`Morph` в `flui-painting`; androidx.graphics.shapes — оракул значений в тестах, код не переносится | Морф форм нужен `LoadingIndicator` и пригодится формам M3 Expressive вообще; дизайн FLUI сначала, чужой фреймворк — проверка (AGENTS.md «Design stance») | владелец (возможность), делегировано (алгоритм) |
| K5 | Частицы: декларативный излучатель, `emit_burst` и пресеты; CPU и один `draw_atlas` | UI-масштаб — тысячи частиц; детерминированно и тестируемо без GPU | владелец |
| K6 | Новых крейтов нет: геометрия в `flui-painting`, общие компоненты — модули `flui-widgets`, Material и Cupertino — в своих пакетах | «Layers, not micro-crates»; решение C2 прошлого раунда; тяжёлых зависимостей в этом наборе нет | делегировано |
| K7 | `ReorderableList`/`ReorderableGrid` строит T33 спека полноты ввода как DnD-сессию `DragReach::Window` (ADR-0211 §9); этот раунд даёт движение поверх сессии и закрепляет контракт колбэков: `on_reorder` один раз при завершении, `to` после удаления, необязательный `on_reorder_preview` | Второй путь перетаскивания нарушил бы ADR-0211; ошибка на единицу в `newIndex` была главной ошибкой пользователей Flutter, и Flutter сменил API; живая перестановка Compose-библиотеки требует синхронного обновления модели, иначе мерцание | делегировано |
| K8 | Карусель на модели ключевых линий с пресетами весов, как `Scrollable` + `SnapPolicy` через `NestedScrollDispatcher` (ADR-0209, после T21/T23 полноты ввода); автопрокрутка opt-in с гарантиями WCAG 2.2.2 и шаблона W3C, шаги с причиной `Programmatic` | Ключевые линии — общий движок для всех раскладок M3; ни Compose, ни Flutter не дают автопрокрутку, а сторонние реализации обычно нарушают 2.2.2 — «батарейки» здесь значат правильную реализацию | делегировано |
| K9 | Конвертер иконок — `cargo xtask icon-import` (AVD XML и пары SVG-путей); данные в исходниках как `const` | Каталог должен расти; Rust-инструменты в xtask, без скриптов | делегировано |
| K10 | ГПСЧ частиц — `fastrand` с сидом (workspace-зависимость) | Зрелый небольшой крейт вместо самописного; сид даёт воспроизводимые кадры | делегировано |
| K11 | `PageIndicator` — общий в `flui-widgets` с двумя типами источника: управляемый (`PageController`, листает) и наблюдаемый (`Animation<f64>`, только показывает); `CupertinoPageControl` — стиль поверх | У Material нет отдельного компонента индикатора страниц; действия листания возможны только у источника с командами, и тип это выражает | делегировано |
| K12 | Отложенный старт перетаскивания и автопрокрутку у краёв не строим: это `DragTrigger::LongPress` (T29) и автопрокрутка сессии (T30) спека полноты ввода | Одна машина DnD на фреймворк (ADR-0211) | делегировано |
| K13 | Под reduce motion переходы иконок мгновенные, а не кроссфейд | Политика движения завершает обычные конечные прогоны на следующем тике (ADR-0195/ADR-0218); кроссфейд потребовал бы `Preserve` в обход выбора пользователя | делегировано |

Первичные источники (Compose `Carousel.kt`, `Keylines.kt`, `LoadingIndicator.kt`,
`ProgressIndicator.kt`; Flutter `reorderable_list.dart`, `carousel.dart`,
`animated_icons.dart`; W3C APG carousel; dnd-kit; SF Symbols) перечислены в issue спека;
значения ниже закрепляются тестами, а не ссылкой.

## Публичный API (эскиз)

```rust
// flui-painting
impl Path {
    pub fn length(&self) -> f64;                               // все контуры подряд, закрывающие рёбра считаются
    pub fn trim(&self, start: f64, end: f64) -> Path;          // доли общей длины; start > end — перенос через начало
    pub fn transform(&self, m: &Matrix4) -> Option<Path>;      // аффинные; перспектива и неконечное — None
    pub fn lerp(a: &Path, b: &Path, t: f64) -> Option<Path>;   // совместимые; неконечное — None
}
pub struct RoundedPolygon { .. }   // new(vertices, rounding), star(..), circle(..), rectangle(..)
pub struct Morph { .. }            // new(&a, &b), path(t) -> Option<Path>
pub mod material_shapes { pub fn soft_burst() -> RoundedPolygon; /* cookie_9, pentagon, pill, sunny, cookie_4, oval, circle */ }

// flui-widgets::icon
pub struct AnimatedIconData { .. }         // const-конструируемые ключевые кадры путей
AnimatedIcon::new(&PLAY_PAUSE, progress).size(24.0).semantic_label("Play");
Icon::new(Icons::FAVORITE).symbol_effect(SymbolEffect::bounce().on_change(count));
Icon::new(Icons::WIFI).symbol_effect(SymbolEffect::pulse().active(searching));
SymbolEffect::replace(other_icon);         // переход между иконками

// flui-widgets::scroll (ReorderableList — T33 полноты ввода; здесь — его движение)
ReorderableList::builder(items.len(), |ctx, i| row(i).key(items[i].id))
    .on_reorder(|from, to| items.move_item(from, to))   // один раз; to — после удаления
    .on_reorder_preview(|from, over| ..)
    .proxy_decorator(|child, index, lift| ..);
Carousel::builder(n, |ctx, scope: &CarouselItemScope, i| ..)
    .layout(CarouselLayout::multi_browse(40.0, 56.0)?)  // фаллибельно: CarouselLayoutError
    .snap(KeylineSnap::SingleAdvance)                   // SnapPolicy (ADR-0209 §9)
    .autoplay(CarouselAutoplay::every(Duration::from_secs(6))?)   // < 5 с — ошибка
    .controller(controller);

// flui-widgets::controls
PageIndicator::controlled(&page_controller, 5);         // листает, «регулируемый»
PageIndicator::observed(progress, 5);                   // только показывает

// flui-widgets::motion
let config = ParticleConfig::confetti();                  // пресет; свой — ParticleConfig::builder()..build()?
ParticleEmitter::new(config).controller(confetti.clone());
let emitted = confetti.emit_burst_at(tap_point, 120);   // сколько выпущено: усечено до свободной ёмкости, 0 под немым TickerMode
```

## Reduce motion

Под `MotionOverride::Reduce` обычные конечные прогоны завершаются на следующем тике
(ADR-0195/ADR-0218); декоративное движение не продлевается через `Preserve` (K13), а
физическая прокрутка и инерция остаются на `Preserve`, как требует ADR-0195. Каждая строка —
тест (M1).

| Компонент | Поведение |
|---|---|
| `AnimatedIcon` | кадр сразу у цели прогресса, без морфа |
| `SymbolEffect` дискретные и бесконечные | статичная иконка |
| `SymbolEffect::replace`, `appear`, `disappear`, `draw_on`/`draw_off` | мгновенно: новая иконка или конечное состояние в следующем кадре |
| Поднятие, сдвиг, посадка в списке | без масштаба; сдвиг, посадка и возврат — мгновенно; автопрокрутка сессии работает (функциональна) |
| Карусель | автопрокрутка выключена; переходы контроллера (`animate_to_item`) — мгновенно; привязка после броска пользователя — физическая прокрутка на `Preserve`, без изменений (ADR-0195) |
| Волнистые индикаторы | амплитуда 0 (плоский Expressive) |
| Неопределённые индикаторы | статичный видимый кадр (ADR-0192) |
| `LoadingIndicator` | одна статичная форма |
| Определённый прогресс | значение прыгает, без твина |
| `PageIndicator` | точки прыгают за позицией без анимации перехода |
| Частицы | не излучаются; уже живущие исчезают в следующем кадре |

## Тестовые швы

Один стол на группу, через публичный API:

- **G:** чистые таблицы в `flui-painting`: длина окружности, квадрата и открытой ломаной;
  отрезок от `-f64::MAX` до `f64::MAX` измеряется как `0.0` и обрезается в пустой путь;
  `transform` пути с `NaN` (тождественная матрица) и масштаб пути с `f64::MAX` — `None`;
  `trim` половины; перенос через начало на одном и на двух контурах; окно через два контура
  даёт два куска; контур нулевой длины не попадает в результат; последовательность команд:
  целиком покрытый замкнутый контур кончается `Close`, частичный кусок — без `Close`; вырожденные доли и пути;
  `transform` — масштаб, поворот, перенос, отказ перспективе (включая полюс `w = 0`) и
  неконечной матрице; `lerp` — точные концы, середина, выход за `[0, 1]`, отказ
  несовместимым путям, неконечному `t` и переполнению; `Morph::path(0/1)` совпадает с
  исходными формами, `path(0.5)` строго между по площади, неконечное `t` — `None`;
  `RoundedPolygon` с ребром `(f64::MAX, 0)–(−f64::MAX, 0)`, двумя вершинами, совпадающими соседними вершинами, коллинеарными вершинами, `NaN`, отрицательным радиусом
  и сглаживанием вне `[0, 1]` — ошибки `ShapeError`; формы
  против значений-оракула androidx.
- **I:** кадр `AnimatedIcon` на 0, 0.5, 1 читается из display list (контрольные точки пути);
  RTL зеркалит; `AnimatedIconData::try_new` отклоняет несовместимые кадры, `NaN`, непрозрачность
  вне `[0, 1]` и неупорядоченные времена; прогресс 1.5 рисует кадр 1, а `NaN` — последний конечный кадр; `Speed::new`
  отклоняет 0, −1, `NaN` и `∞`; `PathEffect` принимает только векторный `AnimatedIcon`
  (глифовой иконке его не передать — проверка компиляции); каждый эффект — строка (масштаб `bounce` на пике, непрозрачность `pulse` на
  полупериоде, `draw_on` — длина нарисованного пути); `icon-import` — фикстура AVD → данные,
  несовместимая пара → ошибка.
- **R:** поверх сессии T33: декоратор подъёма на полпути (высота строго между 0 и 6); сосед
  строго между слотами на 125 мс после смены цели; посадка и возврат при отмене тем же
  движением; клавиатурная перестановка и действие A8 двигают элемент тем же сдвигом;
  `on_reorder` один раз с правильным `to` в обе стороны; отмена без колбэка; приложение
  переставляет модель в `on_reorder`, и посадка доводит тот же элемент (по ключу) из точки
  броска в новый слот без скачка.
- **C:** маска элемента строго между ключевыми линиями на промежуточной прокрутке;
  `SingleAdvance` при большой скорости переходит ровно на один элемент; переход контроллера
  проходит через диспетчер (вложенный родитель получает остаток); тап по краю, где соседний
  элемент виден, а маскированный — нет, достаётся видимому; на дробной прокрутке активный
  индекс — ближайший к фокусной линии, при равенстве меньший, и `on_index_changed` срабатывает
  один раз на смену; `Weighted([f64::MAX, f64::MAX])` даёт две равные доли;
  `jump_to_item(usize::MAX)` переходит к последнему, вызов в пустой карусели ничего не делает,
  `animate_to_item(2)` до первой раскладки открывает карусель сразу на элементе 2; автопрокрутка листает
  после периода; строка на каждый триггер остановки (фокус клавиатуры, фокус ассистивных
  технологий, наведение, нажатие, потеря фокуса окна, контроль паузы), и каждая проверяет,
  что вращение не возобновилось после снятия триггера; `UserInput` вытесняет шаг
  автопрокрутки; с последнего элемента автопрокрутка переходит к первому, в RTL — в порядке
  чтения, а при всех видимых элементах шагов нет; под reduce motion бросок пользователя
  привязывается тем же физическим движением, что и без него, а `animate_to_item` —
  мгновенно; период < 5 с, неконечные и неположительные размеры, нулевая сумма весов, `Hero` с
  выравниванием `NaN` и `Hero` с выравниванием `f64::MAX` —
  ошибки конструирования; семантика «n из N»; меньше элементов, чем слотов.
- **P:** записанные кадры индикаторов: зазор и stop-точка; волна на 50 % прогресса и плоская
  на 5 %; морф `LoadingIndicator` на 325 мс строго между формами; определённый `LoadingIndicator` с
  прогрессом 1.5 рисует SoftBurst, а с `NaN` — последнюю конечную форму; определённые
  круговой и волнистые индикаторы с `NaN`, `∞` и 1.5 рисуют конечную дугу и объявляют
  конечный процент; `MaterialApp` с `RefreshIndicator` рисует `CircularProgressIndicator`, с
  Expressive-темой — `LoadingIndicator`, без `MaterialApp` — `ActivityIndicator`; позиция
  1.5 объявляется как страница 3, 1.49 — как страница 2; на первой странице нет действия
  уменьшения, на последней — увеличения; `PageIndicator`: на дробной
  позиции 1.5 две точки наполовину; управляемый — тап и действия «регулируемый» листают;
  наблюдаемый — действий нет и тап не листает; оба источника — скрытие при одной странице,
  окно из 5 точек при двадцати страницах и значение «страница n из N»; наблюдаемый сэмпл
  `NaN` и `∞` держит последнюю конечную позицию, позиция 9 при пяти страницах — пятая точка;
  ноль страниц — скрыт, без действий и объявления; управляемый индикатор с начальной страницей 3 до первой раскладки показывает и объявляет
  страницу 4 из N и листает от неё; в RTL первая точка справа, тап по левой стороне и
  действие увеличения листают вперёд в порядке чтения.
- **X:** с сидом два прогона дают одинаковые записанные атласы; всплеск на 120 частиц
  создаёт 120 спрайтов в одном `draw_atlas`; тик останавливается после смерти последней
  частицы; всплеск после остановки снова виден в следующем кадре; под `TickerMode(false)`
  всплеск отклонён (0), и после включения ничего не вылетает; всплеск 1000 в излучатель
  ёмкостью 512 выпускает 512, полный — 0, живые частицы не вытесняются; всплеск в точке
  `f64::MAX` с большой скоростью и частицы с поворотом и угловой скоростью около `f64::MAX`
  удаляются до атласа; живые частицы под `TickerMode(false)` на 0.5 с после включения стоят там
  же, где без паузы (фиксированные шаги), а истёкшие за паузу удалены; второй
  излучатель с тем же контроллером не подключается, после размонтирования первого —
  подключается, а всплеск без излучателя выпускает 0; без излучения под reduce
  motion; конфигурации с `NaN`, бесконечностью, отрицательным временем жизни, перевёрнутым
  разбросом и ёмкостью выше границы — ошибки `build`; неконечная точка всплеска — отказ;
  частицы вне семантики.

Задача, которая вводит `RenderBox`/`RenderSliver`, сама добавляет строку
`RENDER_OBJECT_TYPES` и `harness_*` (для `RenderSliverCarousel` — T7).

## Риски

- Ленивый sliver карусели требует, чтобы маскируемый элемент на краю жил вне построенного
  диапазона: держим его отдельным ребёнком sliver на время прокрутки (как призраки
  `AnimatedList`), а не расширяем диапазон.
- Карусель и перестановка ждут ядра полноты ввода (T21/T23 и T29/T30/T33); их задачи в этом
  раунде стоят в графе после них, а не строят временный путь.
- Маскирование элементов карусели на каждом кадре: скруглённый прямоугольник через clip, без
  offscreen-слоя.
- `RoundedPolygon`/`Morph` — объёмная геометрия; закрепляем таблицей против значений-оракула
  androidx, а не визуально.
