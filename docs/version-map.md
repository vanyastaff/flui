# Version map

> Generated by `cargo xtask platform-floor --write` from
> [`platform-support.toml`](../platform-support.toml); edit that file, not this page.

The lowest version of each environment FLUI runs on, and what sets it
([ADR-0244](adr/ADR-0244-os-version-floors-and-gates.md)). Below a version floor FLUI does
not start; where a floor is a requirement rather than a version, a missing one is reported
by name at start. An API newer than the floor is used behind a typed gate, never by raising
the floor.

| Environment | Floor | Set by |
|---|---|---|
| Windows | Windows 10 1507 (build 10240) | the Rust target and D3D12; per-monitor DPI v2 (1703) and later APIs are gates |
| macOS | 10.13 on x86_64, 11.0 on arm64 | wgpu's Metal backend on x86_64; 11.0 is the first arm64 release |
| iOS | 13.0 | UIScene and UIWindowScene, through which the backend gets its window |
| Android | API 23 (Android 6.0) | the backend's own NDK use (`__system_property_get`, the API level read) and `View.getRootWindowInsets` for the safe area; Vulkan or GLES 3.0 |
| Linux | glibc 2.17; a Vulkan 1.0 or GLES 3.0 driver; Wayland with `xdg_wm_base` 1, or X11 with RandR 1.5 | the Rust target, wgpu, and the window and display protocols the backend binds |
| Web | WebGPU or WebGL2 | the browser's graphics API, detected and never read from a browser version |
