### Fixed

- **The iOS Simulator lane's read** (`flui-driver`): a window is another simulator's only when
  it names a UDID `simctl list devices` gives, not any UUID; a simulator that is not available
  no longer counts as sharing the device's window title; a parent that goes away mid-read leaves
  its children reported as unread instead of a shorter list read as whole; and every element the
  Mac's read asks waits the deadline a timeout then names.
