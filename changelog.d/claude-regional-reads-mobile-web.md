### Added

- **`flui-native`**: the macOS, iOS, Android and Web hosts read the user's regional formats:
  Foundation's locale and calendar on Apple, the calendar, the 24-hour setting and Android 14's
  `fw` and `nu` keywords on Android, and `Intl`'s default hour cycle and week info on the Web
  ([ADR-0278](/docs/adr/ADR-0278-regional-formats-are-the-unicode-locale-extension-keys.md)).
