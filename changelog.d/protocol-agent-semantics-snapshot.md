### Added

- `flui-protocol` carries the agent-protocol schema of ADR-0080: `ElementId` and `WindowId` handles (`e12`, `w3`), `Node`, `Tree`, `ReadQuery`, `ActionRequest`, the fifteen `ErrorCode`s, `Retry` and the one-line `outline`, versioned apart from the crate as `PROTOCOL_VERSION` (`0.1`) with a published JSON schema per version. A node's bounds are `rect` in screen pixels or `surface_rect` from a backend that knows no window position, and a reader built on an older schema still reads a newer reply: an unknown role reads as `unknown`, an unknown action name is dropped, an unknown error code reads as `platform`.
- `flui-semantics` reads its published tree as wire nodes (`SemanticsOwner::read_wire`), with roles, names, state and actions as UI Automation reports them, and resolves a wire action back into a semantics action (`SemanticsOwner::resolve_wire_action`), refusing an `expand` or `collapse` the node's committed state does not allow.
- `flui-runtime` adds `SemanticsAgent`, vended by `UiRealm::semantics_agent`: a `Send + Sync` capability that reads a presentation's committed semantics tree and delivers actions to its elements' semantics handlers through the realm's owner inbox, answering failures with ADR-0080 codes.
