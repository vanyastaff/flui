# Material animated icon frames

Key frames of the Material animated icons, one SVG per icon. Each `<g id="frame-NN">` is one
key frame; `data-flui-match-text-direction` marks the icons that mirror under right-to-left
text.

The test regenerates the constants in `src/animated_icons/data/` from these frames and fails
while a committed constant differs. `FLUI_BLESS=1` writes the constants:

```sh
FLUI_BLESS=1 cargo nextest run -p flui-material --test material_it -E 'test(material_icon_constants_match_their_frames)'
```

A new revision is taken by checking Flutter out at it, running the same command with
`FLUI_FLUTTER_DIR=<checkout>` beside `FLUI_BLESS=1`, which rewrites these frames from the
checkout's generated data before the constants, and updating the revision here.

A new icon is a file here with one `<g id="frame-NN">` group a frame, every frame drawing the
same filled paths with the same commands, and its stem in the test's list.
